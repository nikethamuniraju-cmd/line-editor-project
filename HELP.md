# Simple Line Editor - Help

## 1. Insert Line

Adds a new line at the specified line number.

### Usage:
Select option 1.

### Example:
Enter your choice: 1
Enter line number: 1
Enter text: Hello

Output:
Line inserted successfully at line 1.

---

## 2. Delete Line

Deletes a line from the document.

### Usage:
Select option 2.

### Example:
Enter your choice: 2
Enter line number to delete: 1

Output:
Line 1 deleted successfully.

---

## 3. Display Document

Displays all current lines with their line numbers.

### Usage:
Select option 3.

### Example:
Enter your choice: 3

Output:
1: Hello
2: Welcome

---

## 4. Save Document

Saves the current document into a text file.

### Usage:
Select option 4.

### Example:
Enter your choice: 4
Enter filename to save: test.txt

Output:
Document saved successfully to test.txt

---

## 5. Load Document

Loads a previously saved text file.

### Usage:
Select option 5.

### Example:
Enter your choice: 5
Enter filename to load: test.txt

Output:
Document loaded successfully from test.txt

---

## 6. Quit

Exits the line editor.

### Usage:
Select option 6.

### Example:
Enter your choice: 6

Output:
Exiting Line Editor...
Thank you!
